# 📖 Руководство по использованию админ-панели

Это руководство поможет вам управлять контентом бота через интерактивную админ-панель.

## 🚀 Начало работы

### 1. Назначение администратора

Перед использованием админ-панели нужно назначить себя администратором:

```bash
python set_admin.py <ваш_telegram_id>
```

**Как узнать свой Telegram ID:**
- Напишите боту [@userinfobot](https://t.me/userinfobot) в Telegram
- Он покажет ваш ID

**Пример:**
```bash
python set_admin.py 123456789
```

### 2. Открытие админ-панели

После назначения администратором:
1. Откройте бота в Telegram
2. Отправьте команду `/admin`
3. Откроется меню админ-панели

## 📁 Управление категориями

### Добавление категории главного меню

1. Нажмите "📁 Категории" в админ-панели
2. Нажмите "➕ Добавить категорию"
3. Выберите "📋 Главное меню"
4. Введите название категории (например: "Рецепты и аптечка")
5. Введите эмодзи (например: 💊) или отправьте `/skip`
6. Введите описание или отправьте `/skip`
7. Готово! Категория добавлена в главное меню

### Добавление подкатегории

1. Нажмите "📁 Категории" → "➕ Добавить категорию"
2. Выберите "📂 Подкатегория"
3. Выберите родительскую категорию
4. Введите название подкатегории
5. Введите эмодзи или отправьте `/skip`
6. Введите описание или отправьте `/skip`
7. Готово! Подкатегория добавлена

**Совет:** Подкатегории отображаются внутри родительской категории. Можно создавать многоуровневую структуру.

## 📝 Управление контентом

### Добавление контента (статьи, рецепта)

1. Нажмите "📝 Контент" в админ-панели
2. Нажмите "➕ Добавить контент"
3. Выберите категорию, в которую добавить контент
4. Введите заголовок (например: "Рецепт от головной боли")
5. Введите текст контента или отправьте `/skip`
6. Отправьте фото (или отправьте `/skip`)
7. Отправьте файл/документ (или отправьте `/skip`)
8. Готово! Контент добавлен

**Совет:** 
- Фото и файлы опциональны - можно пропустить
- Текст может быть длинным (рецепты, статьи)
- Контент сразу становится доступным пользователям

### Структура контента

Каждый контент содержит:
- **Заголовок** - название материала (обязательно)
- **Текст** - основной текст (статья, рецепт и т.д.)
- **Фото** - изображение (опционально)
- **Файл** - документ, PDF и т.д. (опционально)

## 👥 Управление пользователями

### Просмотр пользователей

1. Нажмите "👥 Пользователи" в админ-панели
2. Увидите список всех пользователей бота
3. Статус показывает доступ:
   - ✅ - пользователь имеет доступ
   - ❌ - пользователь не имеет доступа

### Включение/выключение доступа

1. Откройте "👥 Пользователи"
2. Нажмите на пользователя
3. Доступ переключится (✅ ↔ ❌)

**Важно:** Пользователи без доступа не могут использовать бота.

## 📊 Статистика

1. Нажмите "📊 Статистика" в админ-панели
2. Увидите:
   - Количество пользователей
   - Количество категорий и контента
   - Количество просмотров
   - Популярный контент

## 💡 Советы и рекомендации

### Организация контента

1. **Создайте структуру категорий:**
   - 4 категории в главном меню (оптимально)
   - Подкатегории для детализации
   - Многоуровневая структура для сложных тем

2. **Используйте эмодзи:**
   - Эмодзи делают меню более наглядным
   - Примеры: 🌿, 📚, 💊, 🧪, 👶

3. **Добавляйте описания:**
   - Описания помогают пользователям понять, что в категории
   - Отображаются в меню

### Работа с контентом

1. **Заголовки должны быть понятными:**
   - "Рецепт от головной боли" ✅
   - "Рецепт" ❌

2. **Используйте фото:**
   - Фото делают контент более привлекательным
   - Особенно важно для рецептов

3. **Структурируйте текст:**
   - Используйте переносы строк
   - Добавляйте списки и разделы

### Пример структуры

```
📋 Рецепты и аптечка (главное меню)
  📂 Первая помощь (подкатегория)
    📄 Рецепт от головной боли
    📄 Рецепт от простуды
  📂 Ежедневные рецепты (подкатегория)
    📄 Утренний энергетический рецепт

📋 Однокомпонентные масла (главное меню)
  📂 Популярные масла (подкатегория)
    📄 Лаванда - универсальное масло
    📄 Мята перечная
```

## ❓ Часто задаваемые вопросы

**Q: Как удалить категорию или контент?**
A: Функционал удаления будет добавлен в следующих версиях. Пока можно редактировать через админ-панель.

**Q: Можно ли редактировать категории и контент?**
A: Да, функционал редактирования доступен через админ-панель.

**Q: Как изменить порядок категорий?**
A: Порядок определяется автоматически по порядку добавления. Можно изменить через редактирование категории.

**Q: Сколько категорий можно добавить в главное меню?**
A: Рекомендуется 4 категории для удобства навигации, но можно добавить больше.

**Q: Можно ли добавить контент без категории?**
A: Нет, каждый контент должен принадлежать категории.

## 🔒 Безопасность

- Только администраторы имеют доступ к админ-панели
- Пользователи без доступа не могут использовать бота
- Все действия логируются для аналитики
